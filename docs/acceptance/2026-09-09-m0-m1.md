# OpenBoard M0/M1 acceptance evidence

## Evidence collected

- `npm run verify:core`: contract validator and 47 Node tests pass; TypeScript build is clean.
- `OPENBOARD_PORT=3187 npm start`: daemon starts and `/api/scene` returns the discovered `examples/orders.csv` scene.
- Web smoke tests prove `/api/scene`, `/api/visual/:id`, local D3/Observable Plot asset delivery, spatial controls, and WebSocket mutation events.
- The M1 workflow test covers create → clone/filter → regional patch → arrange → annotate → checkpoint → goto → fork, including parent lineage.
- Persistence tests cover scene snapshots, JSONL operations, checkpoints/forks metadata, and restart-time undo.
- Real browser check with Playwright against a live runtime: one `v1` card changed from `Failure rate by channel` to `Daily failure-rate trend`; DOM reported `Revision 2`, one card, one navigation entry, and a rendered SVG. Console reported zero errors and zero warnings.

## M0 status

Accepted. The same visual id is patched in place, its revision advances once, and the browser updates through WebSocket without a page reload. Query/render responses include deterministic observations, and no scene/history payload contains generated HTML/CSS/React.

## M1 status

Accepted. Two local formats are discoverable and inspectable; structured QuerySpec and guarded read-only SQL work; clone/compose/annotate/history operations are persisted; all frozen marks compile; explicit render limits return `render_limit_exceeded` with suggestions; and restart restores the scene plus navigable history.
