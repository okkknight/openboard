# OpenBoard M0/M1 acceptance evidence

## Evidence collected

- `npm run verify:core`: contract validator and 30 Node tests pass.
- `OPENBOARD_PORT=3187 npm start`: daemon starts; `/api/scene` returned the discovered `examples/orders.csv` scene.
- Web smoke tests prove `/api/scene`, `/api/visual/:id`, local Observable Plot asset delivery, and a WebSocket `visual.changed` event.

## M0 status

- Data inspection/query, visual create/patch, DuckDB, Plot payload compilation, WebSocket event broadcast, and browser render endpoint have automated evidence.
- The browser visual DOM path is not yet covered by a real browser automation test.

## M1 status

- Dataset discovery, clone, compose, annotations, named checkpoints, goto/undo/redo, persistence primitives, and the frozen MCP tool names are implemented.
- Not accepted: checkpoint/fork lineage persistence, replayable history after restart, and a complete end-to-end M1 workflow test.

This file intentionally does not mark M0 or M1 complete until the remaining acceptance items have direct evidence.
